# 四账户策略有效性分析报告

**生成时间**：2026-10-14 15:45 (GMT+8)
**数据来源**：线上服务器 `/opt/a-share-strategy/data/app.db`（只读查询，未修改任何数据）
**样本量**：**2955 条**入池记录（**全量**，非 API 的 500 条截断）

---

## 执行摘要

**一句话结论：当前策略不是 alpha 来源，而是 beta 放大器——它选出的是 2 倍波动的高弹性股票，市场涨时跑赢、跌时大幅跑输；扣掉大盘后整体显著为负。**

三个必须记住的数字：

| 指标 | 数值 | 含义 |
| --- | --- | --- |
| 超额收益 | **−0.67%**（95% CI: −0.96% ~ −0.37%） | 扣掉大盘后仍为负 |
| t 值 | **−4.43**（p < 0.001） | 统计显著，不是运气 |
| 日度 beta / alpha | **2.10 / 0.08** | 2 倍波动，alpha 几乎为零 |

**最反直觉的一条**：追高（日内高位 ≥90% 买入）的超额收益 **+0.11%**，是四个位置桶里**唯一为正**的；而中低位（0.3–0.6）超额 **−1.93%**，表现最差。这与"追高要惩罚"的常规假设**相反**。

## 一、数据说明与限制（先说清楚，否则结论会虚高）

### 拿到了什么

- **全量 2955 条** `watch_tracks` 记录，**绕开了 API 的 `limit ≤ 500` 截断**（该截断曾让样本失真约 6 倍）。
- 有完整 T+3 收益且能匹配大盘基准的有效样本：**2190 条**。
- 时间跨度：2026-09-03 ~ 2026-10-08，共 **20 个交易日**。
- 账号映射（来自 `users` 表）：`soft`=3、`fenshi`=4、`soft_opt`=7、`verify`=8。

### 口径校准（重要）

老三账户的 `source` 字段**一律标记为 `fenshi`**（历史约定，不可改动），所以不能只用 `source` 区分策略。本报告按 `(账号, source)` 映射真实策略：

| 真实策略 | 来源 | 有效样本 n |
| --- | --- | --- |
| 软加权 soft | uid3 + uid8/soft | 1205 |
| 进攻型分时 fenshi | uid4 + uid8/fenshi | 917 |
| 优化软加权 soft_opt | uid7 + uid8/soft_opt | 68 |

### 四条限制（每条都会影响结论的适用边界）

1. **基准只有上证指数**（`market_index_daily` 仅存 `000001.SH`）。选股偏中小盘，用大盘股指数做基准会**高估 beta**。理想基准是中证1000，当前库里没有。
2. **只覆盖 20 个交易日**，且样本期内下跌日占 63%（1383/2190）。这是**单一市场阶段**的结论，不能外推到牛市。
3. **未计入交易成本**（佣金、印花税、滑点）。当前 T+3 持有 3 天，双边成本约 0.1–0.3%，会进一步侵蚀收益。
4. **`soft_opt` 仅 68 条**（< 100），**不足以支撑任何结论**，下文相关数字仅供参考。

## 二、方法

1. **超额收益** = 个股 T+3 收益 − 同期上证指数收益（入池日收盘 → T+3 日收盘）。
2. **显著性**：单样本 t 检验（H₀: 超额 = 0），并给出 95% 置信区间。
3. **beta / alpha**：用 20 个交易日的「策略组合日度收益」对「指数日度收益」做 OLS 回归。
4. **分组检验**：按策略、分数桶、日内位置桶、涨跌日分别聚合，均标注 n。
5. 全程只读，未写入任何数据。

---

## 三、结果

### 3.1 整体：扣掉大盘后仍显著为负

| 策略 | n | 个股 T+3 | 指数同期 | **超额** | 超额胜率 |
| --- | --- | --- | --- | --- | --- |
| fenshi（进攻型分时） | 917 | −0.97% | −0.59% | **−0.38%** | 41.2% |
| soft（软加权） | 1205 | −1.34% | −0.53% | **−0.81%** | 40.3% |
| soft_opt（优化软加权） | 68 | −2.67% | −0.77% | **−1.90%** | 33.8% |
| **合计** | **2190** | **−1.22%** | **−0.56%** | **−0.67%** | **40.5%** |

> 合计：sd = 7.03%，se = 0.150，**t = −4.43**，p < 0.001，95% CI = **[−0.96%, −0.37%]**。

**判读**：指数本身也跌了 −0.56%，说明这段确实是下跌市；但个股跌得更多（−1.22%），**负超额不是行情背锅，是选股本身的问题**。

### 3.2 beta 分解：涨时跑赢，跌时跑输（对称放大）

| 市场状态 | n | 指数 | 个股 | **超额** | 超额胜率 |
| --- | --- | --- | --- | --- | --- |
| 上涨日 | 807 | +0.89% | +2.01% | **+1.12%** | **51.4%** |
| 下跌日 | 1383 | −1.41% | −3.11% | **−1.71%** | 34.1% |

放大倍数：上涨日 **2.26×**，下跌日 **2.21×**——高度对称。

日度回归：**beta = 2.10，alpha = 0.08**。

**判读**：这是本报告最重要的发现。策略选出的是**高弹性品种**（beta≈2），本身不带方向性预测能力（alpha≈0）。它在上涨市中确实能跑赢（超额 +1.12%、胜率 51.4%），但下跌市中会以同样倍数放大亏损。整体为负，只因为样本期内下跌日占 63%。

### 3.3 时间稳定性：策略存在明显的"有效窗口"

| 入池日 | n | 超额 | 胜率 | 指数同期 |
| --- | --- | --- | --- | --- |
| 2026-09-16 | 128 | **+3.48%** | 66.4% | +1.50% |
| 2026-09-15 | 133 | **+1.59%** | 64.7% | +1.23% |
| 2026-09-17 | 107 | **+1.75%** | 53.3% | +1.97% |
| 2026-09-14 | 131 | +0.64% | 57.3% | −0.25% |
| … | | | | |
| 2026-09-22 | 139 | **−2.90%** | 25.9% | −3.25% |
| 2026-09-23 | 146 | **−3.19%** | 28.1% | −2.69% |
| 2026-10-08 | 113 | **−3.86%** | 17.7% | −0.29% |

**判读**：9/14–9/18 那一周策略持续正超额（胜率高达 66%），9/21 之后转持续负超额。**整体均值 −0.67% 掩盖了巨大的时间异质性**——策略不是"一直无效"，而是"只在特定环境下有效"。这与 3.2 的 beta 结论一致：那周正是指数连续上涨的一周。

### 3.4 分数有效性：soft 策略上打分是**反向**的

| 策略 | 分数桶 | n | 个股 T+3 | 胜率 |
| --- | --- | --- | --- | --- |
| soft | <50 | 472 | **−0.57%** | 39.2% |
| soft | 50–69 | 431 | −1.52% | 36.0% |
| soft | **≥70** | 302 | **−2.28%** | **33.4%** |
| fenshi | <50 | 544 | −0.92% | 37.3% |
| fenshi | 50–69 | 200 | −0.85% | 39.5% |
| fenshi | **≥70** | 173 | −1.26% | 39.9% |
| soft_opt | <50 | 42 | −2.86% | 26.2% |
| soft_opt | ≥70 | 15 | −2.40% | 26.7% |

**判读**：
- **soft 策略上打分与收益单调负相关**——分数越高越差（−0.57% → −2.28%，胜率 39.2% → 33.4%）。n 均 >300，这个趋势**可信**。打分模型在 soft 上方向反了或过拟合。
- **fenshi 策略上分数基本无区分度**（−0.92% / −0.85% / −1.26%，胜率几乎持平）。分数在这里不提供信息。
- soft_opt 样本太小（15–42），不可下结论。

### 3.5 追高效应：与常规假设**相反**

| 日内位置 | n | 个股 T+3 | **超额** | 胜率 |
| --- | --- | --- | --- | --- |
| **≥0.9（高位/追高区）** | 514 | −0.39% | **+0.11%** | **47.5%** |
| 0.6–0.9 | 1396 | −1.29% | −0.74% | 39.3% |
| 0.3–0.6 | 252 | −2.66% | **−1.93%** | 32.5% |
| <0.3 | 19 | −1.65% | −1.35% | 36.8% |

**判读**：**买在日内高位的表现最好（唯一正超额 +0.11%），买在中低位的最差（−1.93%）**。这与"追高要惩罚"的设计意图完全相反。

合理解释：能冲到日内高位不回落的票本身就是**强势股**（动量效应），后续 3 天继续走强的概率更高。而"中低位"可能包含了大量**冲高回落**的弱势票——它们曾经到过高位但没守住。

⚠️ 这是相关性，不是因果性。不能直接得出"应该追高"的结论，但足以说明**当前策略的追高惩罚参数方向可能有问题**，值得单独回测验证。

## 四、结论与行动建议

### 结论（按可信度排序）

1. **【高可信】策略无 alpha，是 beta 放大器。** beta≈2.1、alpha≈0.08。这是 n=2190、t=−4.43 支撑的结论。
2. **【高可信】整体负超额显著。** −0.67%，CI [−0.96%, −0.37%]，不含交易成本。
3. **【高可信】soft 策略打分反向。** 分数越高收益越差，单调，n 各 >300。
4. **【中可信】追高惩罚方向可能反了。** 高位超额 +0.11% vs 中低位 −1.93%，n 充足，但需排除"强势股动量"这一混淆因素。
5. **【低可信/样本不足】soft_opt 最差（−1.90%）**，但 n=68，不能定论。

### 建议（按投入产出比排序）

| 优先级 | 动作 | 理由 |
| --- | --- | --- |
| **P0** | 把 `entry_score` 在 soft 策略上的权重**反向或归零**重测 | 打分反向是明确的负贡献，改它成本最低、收益最直接 |
| **P0** | 增加**市场环境开关**：指数趋势向上时才开仓 | beta=2.1 意味着下跌市必亏，择时比选股更关键 |
| **P1** | 复核追高惩罚参数方向 | 当前参数可能在惩罚本该奖励的强势股 |
| **P1** | 换用中证1000 作基准重新评估 | 现有 beta=2.1 可能因基准错配而高估 |
| **P2** | 补 `soft_opt` 样本到 ≥300 条再评估 | 当前 68 条不足以判断 |
| **P2** | 把 T+3 口径扩展到 T+1/T+5/T+10 | 判断是持有期问题还是选股问题 |

### 不该做的事

- ❌ 不要用「最近 500 条」的 API 数据下结论——已证实它与全量偏差明显（soft 账号 500 条样本均值 −1.53%/胜率 33.2%，全量 898 条为 −1.14%/36.4%）。
- ❌ 不要在只看绝对收益的情况下判断策略好坏——必须减基准。
- ❌ 不要因为"上涨日胜率 51.4%"就认为策略可用——那是 beta 的功劳，不是选股能力。
