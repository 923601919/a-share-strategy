## 一、先说结论：数据够不够

**够做「有效性质疑」，还不够做「策略定论」。**

| 维度 | 现状 | 判断 |
| --- | --- | --- |
| 归档样本（有完整 T+3） | soft 500 条、verify 500 条 | 量级够跑分组统计 |
| 时间跨度 | 2026-09-11 ~ 2026-10-08，约 14 个交易日 | **偏短**：只覆盖一个月，无法排除月份效应 |
| 账户/策略隔离 | soft、verify 两个可登录账号 | fenshi / soft_opt 独立账号无凭证，数据需从 verify 的 source 维度取 |

| 日内位置 day_position | 需确认 | 待查 |

**关键限制（必须先说清楚，否则结论会虚高）：**
两账号的 history 接口都被 `limit ≤ 500` 截断了。soft 归档 500 条全部是 `fenshi` 源；
verify 归档 500 条含 `fenshi 184 / soft 299 / soft_opt 17`。**真实总量可能超过 500，当前是「最近的 500 条」样本，不是全量。**
因此任何结论的第一句都要标注「基于最近 500 条归档样本，非全量」。

## 二、已经能看出的信号（初步，未做显著性检验）

归档样本 T+3 收益（同期）：

| 账号 | 来源 | n | 均值 | 胜率 |
| --- | --- | --- | --- | --- |
| soft | fenshi | 500 | -1.53% | 33.2% |
| verify | fenshi | 184 | -1.03% | 39.1% |
| verify | soft | 299 | -2.07% | 36.8% |
| verify | soft_opt | 17 | -2.82% | 17.6% |

**三个必须回答的问题：**

1. **全线负收益** —— 四组 T+3 均值全为负，最好的 fenshi 也只有 -1.03%。这是策略无效，还是这段行情（9月中~10月初）本身是下跌市？**必须先拿大盘同期收益做基准（基准减法）**，否则无法区分 alpha 与 beta。
2. **分数越高收益越差？** verify 的 `by_score_bucket`：score<50 胜率 37.2% / 均值 -1.59%；score>=70 胜率 25.6% / 均值 -3.37%。**打分与收益呈负相关** —— 如果是真的，说明打分模型方向反了或过拟合。但当前 stats 接口的 by_score_bucket 口径与归档样本口径不同，需要用同一份数据重算。
3. **soft_opt 样本仅 17 条** —— 低于最小可用样本（建议 ≥ 30），当前任何关于 soft_opt 的结论都不可下。

## 三、分析计划（分四阶段）

### 阶段 1：数据获取与清洗（基础，必须做对）

- [ ] 通过 API 分页/迭代拉取**全量**归档（当前接口 limit≤500，需确认能否绕开；否则直接从服务器 SQLite 只读导出）
- [ ] 字段标准化：`created_at` 转日期、`t3_return_pct` 数值化、`source` 统一小写
- [ ] 去重：同一 (user_id, code, created_at) 重复入池记录
- [ ] 缺失标注：无 T+3 的样本**排除出收益统计但保留计数**（区分「拿不到」与「收益为零」）
- [ ] 输出：`analysis_dataset.csv`，含 user_account / source / code / score / pct / position / t0..t3 / t3_return

### 阶段 2：基准对照（决定结论真伪的关键）

- [ ] 拉取同期沪深300 / 中证1000 日线，计算相同持有窗口（T+0→T+3）的市场收益
- [ ] 计算**超额收益** = 个股 T+3 收益 − 同期指数收益
- [ ] 判定：如果用超额收益后胜率仍 < 50%，则策略确实无 alpha；若转正，则是 beta 拖累

**不做这一步，后面所有统计都是自欺。**

### 阶段 3：策略有效性检验

| 检验 | 方法 | 输出 |
| --- | --- | --- |
| 分数有效性 | 按 entry_score 分桶（<50 / 50-69 / ≥70）× T+1/T+3 均值与胜率，做**单调性检验** | 分数是否正向预测 |
| 来源对比 | 三策略（soft / fenshi / soft_opt）× 超额收益，**Kruskal-Wallis + 事后两两 Mann-Whitney** | 哪个策略真的更好，差异是否显著 |
| 追高效应 | day_position 分桶（<0.3 / 0.3-0.6 / 0.6-0.9 / ≥0.9）× T+3 | 买在高位是否显著更差（校准追高参数） |
| 时间稳定性 | 按入池周/月分组，看胜率与均值是否漂移 | 策略是否衰减 |
| 显著性 | 单样本 t 检验（均值 ≠ 0）、bootstrap 置信区间 | **每条结论必附 95% CI 与 p 值** |

### 阶段 4：报告产出

- 结构化 Markdown 报告：执行摘要 → 数据说明与限制 → 方法 → 结果（图表）→ 结论与行动建议
- 图表：收益分布箱线图、分数桶均值柱状图、来源对比图、时间序列胜率曲线
- **诚实性约束（对齐本项目既有约定）**：
  - 每个结论必须带 n / CI / p 值 / 样本充足性标注
  - 必须有「永远猜涨」「永远猜跌」基线对照
  - 区分相关性与因果性，不做过度解读
  - 「样本不足」要明确写出来，不用看起来合理的值填坑

## 五、我的建议

先做**阶段 1 + 阶段 2**（数据清洗 + 基准对照），因为：
- 阶段 2 的结果直接决定后面还要不要做 —— 如果超额收益仍显著为负，那当前策略的结论就是「无效」，后面的分桶分析只是找「哪里最无效」；
- 这两步成本低、结论硬，符合你一贯「先看数字站不站得住」的偏好。
